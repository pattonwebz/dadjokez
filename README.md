# Dad Jokez

The source for [dadjokez.com](https://dadjokez.com), a website whose entire
purpose is to tell you a dad joke.

That is the whole thing. There is no product, no roadmap and nobody's growth
metrics riding on it. It exists because dad jokes are funny and building a
small site for one is a pleasant way to spend an evening.

It shows you a joke. There is a button to show you another one. There is a
separate page for dog jokes, because dog jokes deserve their own page. Every
joke has a permalink, so the good ones can be inflicted on other people
directly.

The jokes come from [icanhazdadjoke.com](https://icanhazdadjoke.com), who have
744 of them and to whom I owe a debt I can never repay.
